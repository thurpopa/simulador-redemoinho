# Simulador de Redemoinho

Simulador das equações de Navier–Stokes feito para feira de ciências.

**Abrir o simulador:** https://thurpopa.github.io/simulador-redemoinho/

- **Modo 2D:** ralo da pia, furacão, fumaça subindo, fusão de vórtices, dipolo, esteira de von Kármán e laboratório livre. Os termos da equação podem ser ligados e desligados.
- **Modo 3D:** o colapso autossimilar descrito na prova anunciada pela OpenAI em setembro de 2026, um tanque de água com funil e jato no eixo, e um tornado de fumaça. Dá para soltar objetos (isopor, patinho, madeira, folha, aço, bolha) no redemoinho.
- Abaixo do simulador, a página explica as equações, o método numérico (*Stable Fluids*), a física do vórtice, o Problema do Milênio e traz um roteiro de apresentação.

Roda direto no navegador (Chrome ou Edge) com WebGL 2, sem instalar nada. Todo o código está em um único arquivo, `index.html`.
